# MqttBridge

The `MqttBridge` documentation is split into two main documents:

- [User Guide](USER_GUIDE.md)
- [Technical Reference](TECHNICAL_REFERENCE.md)

## What to open

If you want to quickly enable cross‑home synchronization, configure MQTT settings, and understand how the module is used from the admin UI, start with [User Guide](USER_GUIDE.md).

If you need implementation details, topic format, filtering rules, echo suppression and integration flow with osysHome objects, open [Technical Reference](TECHNICAL_REFERENCE.md).
