# MqttBridge

Документация модуля `MqttBridge` разделена на два основных документа:

- [Руководство пользователя](USER_GUIDE.ru.md)
- [Техническая справка](TECHNICAL_REFERENCE.ru.md)

## Что открыть

Если нужно быстро включить синхронизацию между “домами”, настроить MQTT и понять работу модуля через админ‑интерфейс, начните с [Руководства пользователя](USER_GUIDE.ru.md).

Если нужны детали реализации — формат топиков, правила фильтрации, логика подавления эхо и интеграция с объектной моделью osysHome, откройте [Техническую справку](TECHNICAL_REFERENCE.ru.md).
